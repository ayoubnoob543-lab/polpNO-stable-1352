# Logs privados de pruebas

Esta carpeta pertenece al repositorio privado `polpNO-stable-1352`.

## Flujo seguro

1. En la PS4 abre el host con `?log=1&retry=0&attempts=8&verify=1`.
2. Pulsa **Guardar log** y descarga el `.txt`.
3. Sube el archivo a esta carpeta mediante GitHub o envíamelo aquí para añadirlo con `gh`.
4. No pongas tokens, cookies ni credenciales de GitHub en la PS4.

Los archivos de esta carpeta solo son visibles para los colaboradores del repositorio privado.
